# Execution

**Źródło: LAF 1.6, sekcje 3 i 3.1.4.**

Execution to realizacja architektury przez udział architektów w SDLC. Solution Vision (SV) wiąże konkretną potrzebę biznesową z wysokopoziomowym projektem rozwiązania: komponentami, zdolnościami, interakcjami, zmianami infrastruktury i kluczowymi wymaganiami niefunkcjonalnymi.

SV powinno uwzględniać Reference Architecture, Standards i wiedzę z Component Passports. Zmiany architektoniczne wynikają z wymagań biznesowych, a nie są prowadzone w oderwaniu od nich. Zespoły inżynierskie uczestniczą w tworzeniu i dopracowaniu rozwiązania. Architekt współpracuje blisko z zespołem, ale nie przejmuje jego odpowiedzialności za szczegółowy projekt implementacji.

LAF promuje przyrostowe zmiany: dostarczają wartość wcześniej, pozwalają testować hipotezy korzyści i ograniczają ryzyko dużych, zakłócających transformacji.
