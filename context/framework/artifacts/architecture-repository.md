# Architecture Repository (REPO)

**Źródło: LAF 1.6, sekcje 3 i 3.1.5.**

Architecture Repository jest centralnym miejscem przechowywania artefaktów LAF i źródłem informacji wspierającym decyzje o Solution Vision. Powinno łączyć:

- stan przyszły — Reference Architecture i oczekiwane zdolności;
- zmiany dostarczane — aktywne wymagania i powiązane Solution Visions;
- stan obecny — atrybuty komponentów w Component Passports.

Kształt repozytorium, lista właściwości aplikacji oraz sposób przedstawienia zdolności i SV zależą od organizacji. Repo powinno dać się zmieniać i zawierać minimalny zestaw danych potrzebny do oceny komponentów lub przeprojektowania RA. Koszt pozyskiwania danych wpływa na ich aktualność i jakość.

LAF jest niezależny od narzędzi; można zacząć od arkusza, a automatyzację dobrać do potrzeb. W środowisku AI-augmented repozytorium może wspierać dostęp agentów do MRAC, przy zachowaniu synchronizacji z artefaktami czytelnymi dla ludzi.
