# Reference Architecture (RA)

**Źródło: LAF 1.6, sekcja 3.1.1.**

RA to długoterminowa, wysokopoziomowa wizja architektoniczna dla obszaru biznesowego. Wskazuje pożądany stan środowiska aplikacyjnego, docelowe Components, Capabilities i relacje między nimi. Powinna zawierać krótki opis komponentów i hipotezę korzyści z ich wdrożenia.

RA jest kierunkiem dla późniejszych Solution Visions. Nie jest sztywnym planem transformacji z harmonogramem, budżetem i szczegółowymi stanami pośrednimi. Może ewoluować wraz z potrzebami biznesu, rynkiem i technologią. Powstaje we współpracy z jednostkami biznesowymi; guide zaleca przegląd co najmniej raz w roku.

## Objaśnienie

Przy ocenie inicjatywy pytaj, jaki przyrost zdolności wnosi i jak wpływa na kierunek RA. Zgodność nie musi oznaczać natychmiastowej realizacji całego stanu docelowego.
