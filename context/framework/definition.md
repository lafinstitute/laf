# Definition

**Źródło: LAF 1.6, sekcja 3.**

Definition tworzy wspólne podstawy do podejmowania decyzji architektonicznych. Współpracując z interesariuszami, architekci opracowują:

- **Reference Architecture (RA):** długoterminowy kierunek dla środowiska aplikacyjnego i docelowych zdolności.
- **Standards (ST):** minimalne wspólne zasady zapewniające spójność i przewidywalność.
- **Component Passports (CP):** zwięzłe opisy stanu komponentów; ich dane są odświeżane w ramach Component Portfolio Assessment (CPA).

Te artefakty nie są odizolowanymi dokumentami. RA opisuje aspirację, Standards ograniczają niepożądaną zmienność, a CP/CPA dostarcza wiedzy o aktualnym portfelu. Razem stanowią wejście do rozważań nad Solution Vision.

## Objaśnienie

Definition nie jest jednorazową fazą wdrożeniową. Artefakty wymagają aktualizacji w miarę zmian strategii, technologii, regulacji i wiedzy zdobytej podczas realizacji.
